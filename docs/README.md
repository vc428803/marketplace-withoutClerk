## 文件管理原則

1. 每個主要開發階段建立獨立的架構文件。
2. 使用 Mermaid 繪製 GitHub 可直接預覽的流程圖。
3. 視覺設計圖統一存放在 architecture/images。
4. 區分規劃中、開發中、已完成及待驗證。
5. 重大架構變更應記錄原因及取捨。

> 注意：設計文件不代表功能已完成，實際狀態以 ROADMAP 為準。
